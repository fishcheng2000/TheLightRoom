# THE LIGHT ROOM 微光所｜官方網站

高雄鳳山．光療美甲／仿真穿戴甲／冰感無痛除毛／100 億光保養  
單一 `index.html`，無需伺服器與資料庫，可直接發布或離線開啟。

---

## 一、發布到 GitHub Pages

1. 在 GitHub 建立新的 repository，例如 `lightroom`，設為 **Public**。
2. 上傳 `index.html`（檔名必須小寫，放在 repo 根目錄）與本 README。
3. 進入 repo 的 **Settings → Pages**。
4. Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/ (root)**，按 Save。
5. 等待約 1 分鐘，網址會顯示在同一頁：  
   `https://你的帳號.github.io/lightroom/`
6. 把這個網址放到 IG 個人簡介、LINE 圖文選單、Google 商家。

> 想用自訂網域（例如 `thelightroom.tw`）：在 Settings → Pages 的 Custom domain 填入網域，再到網域商把 DNS 指向 GitHub Pages 即可。

## 二、日常維護：只改「設定區」

打開 `index.html`，搜尋 `① 基本設定`，往下六個區塊就是全部可調內容。

| 區塊 | 用途 |
|---|---|
| `CONFIG` | LINE ID、連結、**活動公告開關** |
| `NAIL` | 光療美甲、穿戴甲價格與工時 |
| `HAIR` | 除毛部位、組合優惠、加價 |
| `GLOW` | 光保養單堂與包堂 |
| `TIERS` | 儲值方案與回饋 |
| `PRICE` | 價目表顯示文字 |

### 開啟活動公告

```js
notice: {
  active: true,                  // 改成 true 就會出現在首頁
  title: '中秋限定活動',
  body: '儲值滿一萬再送腋下除毛一堂。',
  when: '活動期間：9/1 – 9/30'
}
```

改成 `active: false` 就整塊隱藏，版面不會留空。

### 調整價格

例如單色光療漲價：

```js
const NAIL = { base: 699,  →  base: 799,
```

價目表與試算器會同時更新，不需要改兩個地方。

## 三、功能說明

- **價目表**：四個分類，資料與試算器共用同一份設定。
- **價錢試算**：
  - 美甲以「指」計價，可加購延甲、卸甲，支援手足同時。
  - 除毛勾選部位後**自動套用最划算的組合價**並顯示省下金額；「全身除毛」為排他選項。
  - 光保養包堂自動換算平均每堂與省下金額。
  - 三類可同時累計，顯示總金額與預估總時長。
- **一鍵預約**：填完姓名電話後產生完整訊息，複製到剪貼簿並開啟官方 LINE 對話。若系統未自動帶入，畫面會保留訊息供長按複製。
- **導航**：直接喚起 Google 地圖導航到保泰路 270 巷 15 號。
- **選單**：底部「選單」可跳到任一區塊。

## 四、隱私

客人填寫的姓名、電話、生日只在瀏覽器本機組成文字訊息，**不會上傳到任何伺服器**，網站也沒有後端與資料庫。

---

## 五、注意事項

- 中文字體由 Google Fonts 載入，離線開啟時會自動改用系統字體，不影響功能。
- 工時為預估值，僅供排班參考。
- 「手足同時」以基礎光療兩份計算，實際價格以現場為準。
- 除毛「包三堂 9 折」目前套用於該分類的整筆金額。
